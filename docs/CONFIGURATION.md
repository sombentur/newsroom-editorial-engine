# Configuration

All private configuration lives in `backend/.env` (created by `Setup Local.cmd` from `backend/.env.example`; ignored by Git). Restart the app after changing it. Never paste this file, or any key, into chat, issues or screenshots.

Most day-to-day settings (websites, WordPress logins, AI keys, prompts, operating mode, pauses) are edited **inside the app** and stored in the local database; the environment file holds the runtime defaults and safety switches.

## Local runtime (filled in by Setup)

| Variable | Meaning |
|---|---|
| `MONGO_URL` | Local database address. The launcher always uses `mongodb://127.0.0.1:<NEWSROOM_MONGO_PORT>` |
| `DB_NAME` | Database name (`editorial_desktop`) |
| `APP_URL` | The app's own address (`http://127.0.0.1:8001`); used for sessions, trusted hosts and CSRF checks |
| `CORS_ORIGINS` | Allowed browser origins (loopback only) |
| `SESSION_SECRET` | Random secret that signs sessions and CSRF tokens (generated by Setup) |
| `WP_CREDENTIAL_ENCRYPTION_KEY` | Key that encrypts WordPress Application Passwords at rest (generated by Setup). Losing it makes saved passwords unreadable; back it up with the database |
| `LOCAL_SETUP_ENABLED` | Set to `true` by the launcher so the first visit can create the administrator account |
| `NODE_ENV`, `PORT`, `LOG_LEVEL` | Informational defaults |

Ports can be overridden at start time without editing the file: `NEWSROOM_PORT` (app, default 8001) and `NEWSROOM_MONGO_PORT` (database, default 27018). Note that the Chrome Bridge extension expects the app on port 8001.

## AI providers

| Variable | Meaning |
|---|---|
| `GEMINI_API_KEY` | Google Gemini API key (Setup Wizard → AI Providers stores it here) |
| `GEMINI_RESEARCH_MODEL` | A Deep Research agent name (not a chat model) |
| `GEMINI_WRITING_MODEL` | Model that formats the report and writes articles |
| `GEMINI_FAST_MODEL` | Fast model for scoring discovered topics and for the Chrome Bridge page planner (default `gemini-flash-latest`) |
| `OPENAI_API_KEY`, `OPENAI_IMAGE_MODEL` | OpenAI key and image model (16:9 thumbnails) |
| `RESEARCH_AI_PROVIDER`, `WRITING_AI_PROVIDER`, `IMAGE_AI_PROVIDER` | `gemini` or `openai` per step |
| `BROWSER_CONTROLLER_PROVIDER`, `BROWSER_CONTROLLER_MODEL`, `BROWSER_CONTROLLER_FALLBACKS` | Which API decides each Chrome Bridge page step, with fallbacks when a model is overloaded |
| `RANKMATH_API_KEY` | Optional Rank Math account key |
| `KANNADA_AI_AUDIT` | `true` adds an AI language/fact audit and one rewrite pass for Kannada articles |
| `THUMBNAIL_FONT_PATH` | A font with Kannada glyphs for any text the app renders itself (Windows default `C:/Windows/Fonts/NirmalaB.ttf`; the font is not redistributed) |

The Gemini free tier allows only a small number of requests per model per day; topic scoring and the page planner slow down or pause when it is exhausted.

## Safety switches

| Variable | Default | Effect |
|---|---|---|
| `OPERATING_MODE` | `review` | `review`: nothing publishes; `research_only`: research only; `auto`: full pipeline (also needs the in-app mode) |
| `DRY_RUN` | `true` | Blocks every WordPress write and the publishing preflight |
| `REPAIR_LOCK` | `true` | Automatic publishing cannot be switched on while set |
| `SCHEDULER_ENABLED` | `false` | Background scheduler gate (the in-app Scheduler switch must also be on) |
| `AUTO_PUBLISH_ENABLED` | `false` | Allows unattended publishing (also needs `auto` mode and the site's Auto switch) |
| `HIGH_RISK_REVIEW_REQUIRED` | `true` | Flagged subjects (crime, children, elections, scams…) wait for your approval |
| `MANUAL_AI_ENABLED` | `false` | Allow AI calls you trigger by hand while publishing stays locked |
| `SOURCE_GROUNDED_RESEARCH_ENABLED` | `false` | Allow the grounded-search research adapter |

Empty or invalid booleans fail closed. Global **Pause** and **Stop All** in the app's header override everything.

## Where things are stored

| Location | Contents |
|---|---|
| `backend/.env` | This configuration |
| `.local/mongodb/` | The database (sites, topics, articles, images, audit log) |
| `.local/logs/mongodb.log` | Database log |
| `.local/runtime.json`, `.local/stop.request` | Launcher state |
| `.venv/`, `frontend/node_modules/`, `.tools/`, `.cache/` | Installed dependencies, portable MongoDB and Yarn (recreated by Setup) |

Back up `backend/.env` together with `.local/mongodb` while the app is stopped.
